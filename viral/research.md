# 연말결산 앱 리서치

작성: 2026-09-24 · 상태: 후보 검토 중(확신도 **중하**) · 목표 출시: 2026-11-25 전후

> 한 줄 요약: 폰에 자동으로 쌓인 데이터(사진·걸음·캘린더)와 사용자가 내보낸 파일(카톡·넷플릭스·
> 틱톡·구글 타임라인)을 모아 **"스포티파이 Wrapped 같은 연말결산 카드"**를 만들어 주는 앱.
> 아이폰·안드로이드 둘 다 출시.

---

## 1. 아이디어

- **연말결산 ≠ 연말정산.** 세금이 아니라 "올해 너는 이런 사람이었다"를 카드로 보여주는 것.
- 레퍼런스: 스포티파이 Wrapped, 유튜브 리캡, Receiptify(영수증 모양 결산).
- 공유 장치: ②수치형 + ③결과물형. 카드 여러 장이라 **컨테이너 구조**(카드 추가 가능)와도 맞음.

## 2. 수요 근거 (측정값)

### 시즌성
- 네이버 블로그 표본 200건 중 12월 비중: `스포티파이 연말결산` **70%**, `유튜브뮤직 리캡` **78%**.
- 피크: 12/3~4 (스포티파이 발표일). 유튜브 리캡도 12/2~5.
- 유튜브 `연말결산` 상위 15개 영상 합계 **1,660만 뷰**(25/11/20~26/1/15) → 천장 컷(월 1,000만) 통과.
  단, 대부분 크리에이터 콘텐츠이지 앱이 만든 카드가 아님.
- 연말 외에도 블로그에 "9월 결산", "여름결산" 같은 **월별·시즌 결산**이 꾸준히 올라옴 → 연중 운영 근거.

### 사람들이 공유하는 것
| 패턴 | 근거 |
|---|---|
| **"내 1위"(정체성)** | 스포티파이 결산 블로그 상위 단어: `임영웅` 62회, `최애`, `가장 많이 들은`. 들은 시간(분)은 거의 안 나옴 |
| **성격 라벨** | 유튜브 리캡 영상 제목 "내 유튜브 성격은?", 타임라인 유행의 "역마살 수치화" |
| **창피할 만큼 작은 숫자** | "방송만 하는 버튜버의 하루 걸음수는?" 11만 뷰, "눈물나는 한국인의 위치 추적" 460만 뷰 |
| **유명인과 비교** | "빠니보틀은 지구를 몇 바퀴 돌았을까?" |
| **AI에게 평가당하기** | 넷플릭스 시청기록 → "챗GPT한테 평가당하기", "덕후 판별법" |
| **영상 형식(릴스)** | 타임라인 유행은 이미지가 아니라 짧은 세로 영상으로 퍼짐 |

## 4. 가져올 수 있는 데이터

### A. 권한만 주면 자동
| 데이터 | 아이폰 | 안드로이드 | 카드 예시 |
|---|---|---|---|
| 사진첩 | ✅ "전체 사진 허용" 필요 | ⚠️ 구글플레이 정책: 전체 사진 접근은 갤러리급 핵심 기능만, 신청서 심사 | 최애 피사체, 셀카·캡처 수, 시간대 라벨, 사진 위치로 이동 지도 |
| 걸음·거리·계단·수면 | ✅ 과거 전부 | ✅ 기본 30일, 과거는 `PERMISSION_READ_HEALTH_DATA_HISTORY` 추가 요청 | 서울→부산 N번, 롯데타워 N번 |
| 앱 사용시간 | ❌ 애플이 의도적으로 차단(스크린타임 확장 샌드박스) | ✅ 사용자가 설정에서 직접 허용. 몇 달 치 남는지는 실기기 테스트 필요 | 올해 유튜브 N시간(안드로이드 전용 보너스) |
| 캘린더 | ✅ | ✅ | 올해 약속 N개 |
| 음악 | ❌ | ❌ | 스포티파이 API는 신규 앱 5명 제한(25/5~), 멜론 API 없음 → 제외 |

### B. 사용자가 파일을 내보내면
| 데이터 | 방법 | 대기 | 카드 예시 | 비고 |
|---|---|---|---|---|
| 카카오톡 | 채팅방 → 대화 내보내기 → 공유로 앱에 바로 | 즉시 | 제일 많이 말 건 사람, 단톡방 지분율, ㅋ 개수, 새벽 톡 | 단독 분석 앱은 레드오션(텍스트앳 583, 신규 0~16). **카드 한 장으로** |
| 넷플릭스 | PC 웹에서 시청기록 CSV | 즉시 | 올해 N편, 성향 판정 | 지금 수요 확인됨(아래) |
| 구글 타임라인 | 구글지도 앱 설정 → 타임라인 내보내기 | 즉시 | 이동 경로 영상, 역마살 지수 | 타임라인은 기본 꺼짐 → 데이터 있는 사람 적음 |
| 유튜브 | 구글 테이크아웃(JSON) | 수 분~수 시간 | 올해 최다 시청 채널 | 시청 횟수만 있고 시청 시간 없음. 앱 직결 API는 유럽 전용 |
| 틱톡 | 앱 설정 → 내 데이터 다운로드(JSON) | **1~4일** | 올해 본 영상 수, 시간대 | 아래 5-3 참고 |

**이메일로 받는 방식은 안 씀**: 남의 대화가 우리 서버에 쌓이는 개인정보 문제 + 메일 서버 운영 부담.
모든 분석은 **폰 안(또는 브라우저 안)에서만** 처리하고 서버로 보내지 않는다.

## 5. "내보내기 → 분석 → 공유" 사례

### 5-1. 구글 타임라인 비주얼라이저 (8월, 식음)
- 웹사이트. 타임라인 파일을 올리면 1년 이동 경로를 영상으로 만들어 줌.
- 8/20경 인도네시아 틱톡 → 한국 전파. 방아쇠: `평양냉면`(구독 4.3만) 쇼츠 8/25 **460만 뷰**.
- 네이버: 8/26 하루 약 200건 피크 → 9월 하루 1~3건. **1회성, 2주 만에 소멸.**
- 따라 만든 앱들(Timeline Visualize, My Timeline 등)은 전부 리뷰 0~1 → 단독 앱으로는 안 함.
- 우리 앱에서는 **사진 위치 정보로 자동 이동 지도** + 타임라인 파일은 선택 업그레이드.

### 5-2. 넷플릭스 시청기록 → AI 분석 (9월, 진행 중)
- 넷플릭스코리아 10주년 공식 캠페인이 방아쇠. 크리에이터 영상에 `[넷플릭스 코리아 10주년 기념]` 태그
  (이종범 77만, 썸머썸머 15만) → 규칙상 **광고 집행**, 자연 바이럴 아님.
- 네이버: 평소 하루 2건 → 9/14부터 급증, 9/23 **60건(30배)**.
- 광고 태그 없는 `진돌` "새로운 덕후 판별법"도 31만 뷰 → **"기록을 보여주고 평가받기" 형식 자체에 반응**.

### 5-3. 틱톡 데이터 결산 (해외 웹툴 존재, 한국 수요 미확인)
- 해외: 틱톡 공식 결산이 없어서 개인 개발자 웹툴(TTWrapped 등)이 자리를 채움.
- 한국 앱스토어: `틱톡 결산` 검색 **0건** → 자리는 비어 있음.
- 한국 수요: 12월 `틱톡 결산` 블로그 185건(평소 월 5건 내외)이지만, 내용이 **"올해 유행한 틱톡 챌린지·
  아이돌 모음"**이지 "내 틱톡 사용 결산"이 아님. `틱톡 데이터 다운로드` 검색은 틱톡라이트 설치 글뿐.
  → **한국 사용자는 많지만 "내 틱톡 기록 결산" 수요는 아직 증거 없음.**
- 기술 리스크: 데이터 받는 데 **1~4일** 걸림(유행 순간을 놓침). 시청기록 파일은 **영상 링크+시각 위주**로
  알려져 있어 "최다 시청 크리에이터"를 뽑으려면 링크를 별도로 풀어야 할 수 있음(실제 파일로 확인 필요).
- 대응: 11월 중순에 "12월 결산 미리 신청하기" 안내로 대기 시간을 앞당긴다.

### 5-4. 상시 수요
- 카톡 대화 → 챗GPT 썸 분석: 26/5부터 월 50~80건 꾸준.
- 인스타 언팔 확인: 항상 있는 수요, 앱은 포화(Reports+ 13,473 · Followers Tracker 8,190).

### 공통 패턴
1. **전부 앱이 아니라 웹이나 챗GPT에서 일어났다.** 넷플릭스 CSV는 PC 웹에서만 받을 수 있다.
   → 파일 내보내기 기능은 **설치 없는 웹 버전**, 자동 데이터는 **앱**. 앱+웹 구조 검토.
2. **최대 경쟁자는 챗GPT(무료).** 우리가 줄 것: 공유용 카드·영상, 친구 비교, 여러 데이터 합산, 프롬프트 불필요.
3. 숫자보다 **판정("너는 ○○형")**을 공유한다.

## 6. 설계안: "폰이 기억하는 나의 2026"

1. **최애 카드**: "올해 가장 많이 찍은 것: 고양이 1,204장" (폰 안 AI 분류)
2. **성격 라벨**: 찍은 시간대 → "새벽 2시 캡처러", 이동 → "역마살 12점 방구석형"
3. **창피한 숫자**: "올해 셀카 3장", "12월 하루 평균 1,847보: 버튜버급", "집-회사 반복 247일"
4. **한국식 단위**: 서울→부산 2.3번, 롯데타워 14번, "빠니보틀의 3%"
5. **친구 비교**: 카드 하단 "너는 몇 장?" → 단톡방 랭킹
6. **파일 카드(선택)**: 카톡 썸 판정 · 넷플릭스 성향 판정 · 틱톡 · 타임라인 이동 영상
- 출력: 9:16 이미지 + **10~15초 세로 영상(릴스용)**
- 연중 운영: 월별·시즌 결산(여름결산·추석결산), 제목에 시즌 명사 갈아끼우기

## 7. 일정·공수

- 크로스플랫폼(Flutter 또는 React Native) + 사진/건강 부분만 플랫폼별 연결.
- 1차(자동 데이터 + 카톡): 아이폰 단독이면 약 4주(40~50h), **양 플랫폼 약 6주(60~70h)**.
- 마감: 스포티파이 발표(12/3경) 전 심사 통과 → **11/25 출시**, **10월 초 착수**.
- 대안: 아이폰 먼저, 안드로이드는 1월(월별 결산으로 연결).
